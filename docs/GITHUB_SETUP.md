# GitHub setup — Windows PowerShell

> The prepared starter archive intentionally omits Replit's internal `.git` directory. Create a new private repository on GitHub, e.g. `kwa-njenga-school-website`, under your own account, with **no autogenerated README or licence** (these are already in the project).

Open the **workspace root** in VS Code, then run:

```powershell
git init -b main
git config --global user.name "YOUR GITHUB DISPLAY NAME"
git config --global user.email "YOUR VERIFIED GITHUB EMAIL OR NOREPLY EMAIL"
git add .
git status
# Inspect the file list carefully; no credentials, learner records, guardians' details, or consent forms.
git commit -m "chore: import audited Replit school website source"
git remote add origin https://github.com/YOUR-USERNAME/kwa-njenga-school-website.git
git push -u origin main
```

Replace values with your own; authentication may require the GitHub web sign-in flow or Git Credential Manager. Configure a verified or noreply address on GitHub if you want qualifying contributions to appear in your profile. Never paste your GitHub password or personal access token into this chat or source code.

## Working cadence

- Create a GitHub issue describing a user-visible or technical goal, acceptance criteria and test plan.
- Use a dedicated branch: `git switch -c fix/real-form-status`.
- Make one coherent change, verify it, `git add`, `git commit -m "fix: ..."` and `git push -u origin fix/real-form-status`.
- Open a pull request and review its diff/screenshots; merge to `main` after checks pass.
- Mark the issue closed and update the project board or changelog.

**Visibility:** contributions normally count when commits use an account-associated email and reach a qualifying branch; pushing to a feature branch alone doesn't necessarily update the GitHub contributions graph until merged. Do not manufacture commits.

## Privacy

Keep the repository private during client/school approvals. It can later have an approved public case study or selected open-source version with any personal or proprietary information stripped.
